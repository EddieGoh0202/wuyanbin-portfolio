# 样本索引

本文件是本项目语料库的检索索引，供 `content-style-analyst` 选样时**优先读取**。
用法：先读本索引，按「类型标签 + 论证主线」定位 5-8 篇候选，再打开对应原文精读 3-5 篇。选样阶段不要全库扫描正文。

**维护规则：新增文章时须同步在对应栏目表中补一行；删除文章时同步删行。**

字段说明：
- **论证主线**：文章的核心逻辑链，是选样时最重要的匹配字段。跨领域的结构同构常出现在此列（例如"儿童纠纷"与"跨省执法"事件领域无关，但论证骨架相同）。
- **体裁**：事件评论 / 事件演进复盘 / 观点汇编＋点评 / 声誉风险评析 / 综述研究型 / 方法论讲解 / 案例拆解
- **篇幅**：正文字数，取整到百位。
